# Bluestock N100 Financial Analytics Dashboard

## Overview

Bluestock N100 is a financial analytics dashboard built using Python and Streamlit. The application provides company financial analysis, screening, peer comparison, trend analysis, capital allocation insights, valuation metrics, and annual report access for companies in the N100 universe.

---

## Features

- Company Financial Profile
- Financial KPI Dashboard
- Financial Screeners
- Peer Group Comparison
- Trend Analysis
- Sector Analysis
- Capital Allocation Dashboard
- Annual Report Links
- Valuation Dashboard
- CSV & Excel Export

## Installation

Clone the repository

```bash
git clone https://github.com/GOODFIGHTERSOY/bluestock_n100_Krithik.git
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate

Windows

```bash
venv\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
streamlit run app.py
```

The dashboard opens at

```
http://localhost:8501
```
